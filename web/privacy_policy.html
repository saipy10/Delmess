DelMess ("we", "our", or "the App") is committed to absolute user privacy, local data sovereignty, and radical transparency. This Privacy Policy details how DelMess processes data strictly on your physical Android device.

1. 100% On-Device Zero-Cloud Architecture

DelMess is engineered with an offline-first, on-device architecture. The production release build of DelMess does NOT declare or request Android's android.permission.INTERNET. Because no network permission exists in the release build, the application is physically and technically incapable of transmitting your messages, sender headers, financial data, OTPs, or device identifiers over the network to external servers or cloud services.

2. SMS Processing & TRAI Header Decoding

DelMess analyzes SMS messages exclusively on your phone to organize them into structured categories:

  • Transactional: Bank transaction alerts, UPI transfers, ATM withdrawals, and credit/debit card alerts.
  • Service: E-commerce order confirmations, courier tracking, ride-hailing updates, and utility notifications.
  • Promotional: Marketing broadcasts, seasonal sales campaigns, and promotional coupon codes.
  • Government: Official government alerts, Aadhaar/DigiLocker notifications, and public advisories.
  • Other / Spam: Unclassified or low-priority personal and automated messages.

DelMess decodes commercial alphanumeric sender headers regulated by the Telecom Regulatory Authority of India (TRAI) (e.g. AX-HDFCBK, AD-SWIGGY-T, VM-AMAZON) to identify recognizable brand identities. All parsing, categorization heuristics, and pattern matching run client-side using local Dart code and SQLite queries.

3. Ephemeral OTP Intelligence — Zero Storage

DelMess extracts one-time passwords (OTPs) and verification codes dynamically in-memory when rendering message views to enable convenient one-tap clipboard copying.

🔒 Ephemeral OTP Guarantee

DelMess never persists extracted OTP codes into its SQLite database on disk. Extracted OTP credentials exist only ephemerally in active memory during UI display and evaporate as soon as the screen is dismissed.

4. Sandboxed Storage & Database Isolation

DelMess stores categorized message metadata, user labels, and application settings in an encrypted or sandboxed local SQLite database managed by the Drift ORM at:

/data/user/0/com.delmess.smsorganizer.delmess/databases/delmess.sqlite

Android's Linux kernel UID sandbox isolates this directory, strictly preventing any other installed app from accessing or inspecting DelMess records. DelMess never writes your messages to public shared external storage.

5. Permissions Requested & Purpose

DelMess requests only the permissions strictly required to execute its core function as an SMS Organizer and Default SMS Handler:

Android Permission Core Purpose Justification
READ_SMS Indexes existing SMS messages on the physical device into organized category feeds.
RECEIVE_SMS Detects incoming SMS in real-time to organize incoming notifications and extract OTP chips.
SEND_SMS Used when DelMess is designated as the Default SMS App (ROLE_SMS) to compose and send outgoing text messages.
RECEIVE_MMS / RECEIVE_WAP_PUSH Required by Android OS specifications to satisfy the Default SMS App contract.

DelMess does NOT request:

  • ❌ INTERNET (Zero network access)
  • ❌ ACCESS_FINE_LOCATION or ACCESS_COARSE_LOCATION (No location tracking)
  • ❌ READ_CONTACTS (No address book access)
  • ❌ CAMERA or RECORD_AUDIO (No media capture)
  • ❌ READ_EXTERNAL_STORAGE (No shared disk access)

6. Third-Party Libraries, Analytics & Crash Reporting

  • Analytics: ZERO analytics tracking. We do not use Google Analytics for Firebase, Mixpanel, Amplitude, Segment, Flurry, or Facebook SDK.
  • Advertising: ZERO advertising SDKs. DelMess is 100% ad-free.
  • Crash Reporting: ZERO cloud crash reporters (No Firebase Crashlytics, Sentry, or Bugsnag). Crash stack traces remain strictly within Android's local system logs (logcat).
  • Open-Source Components: All open-source packages (Flutter, Riverpod, Drift, GoRouter, SharedPreferences) execute entirely on-device with zero remote telemetry.

7. User Data Deletion & Retention

You have full autonomy over your data:

  • In-App Deletion: Permanently delete single messages, threads, or empty the Trash folder.
  • In-App Database Reset: Erase all indexed messages and custom labels instantly via Settings > Privacy & Security > Delete All Local Data & Cache.
  • Android System Clear Storage: Purge all app data at any time via Android Settings > Apps > DelMess > Storage > Clear Storage.
  • App Uninstallation: Uninstalling DelMess immediately erases all SQLite database files, preferences, and caches from your device.
